COMPACTADOR DE PDF E FOTOS EM PDF
===================================

O QUE ESTE PROGRAMA FAZ
------------------------
1) Compacta arquivos PDF para ficarem abaixo do tamanho escolhido (12 MB,
   5 MB, ou outro valor que você digitar) — útil para sistemas judiciais
   (PJe, e-SAJ, Projudi, etc.) que limitam o tamanho dos arquivos enviados.
   A compactação NUNCA deixa as imagens ilegíveis; se o arquivo não couber
   no tamanho escolhido nem no nível máximo de compactação, o programa
   divide o PDF em partes numeradas (parte1_de_N, parte2_de_N...), cada
   uma dentro do limite.
2) Transforma fotos (JPG, PNG, HEIC, etc.) em arquivos PDF, gerando um PDF
   separado para cada foto selecionada. Essa conversão é direta, sem
   opções de tamanho máximo (fotos raramente passam do limite).
3) Junta vários PDFs em um único arquivo, na ordem que você escolher —
   quando um termina, o próximo começa em seguida. O resultado é sempre
   1 (um) único arquivo PDF, nunca dividido em partes.
4) Se atualiza sozinho: toda vez que o programa .exe abre, ele confere em
   segundo plano se existe uma versão mais nova publicada. Se existir,
   pergunta se você quer atualizar agora — ao confirmar, o programa baixa
   a versão nova, fecha e abre de novo sozinho, já atualizado. Não precisa
   internet para usar o programa normalmente; a checagem é só um "a mais",
   e se não tiver internet ou o site estiver fora do ar, o programa
   continua funcionando normalmente sem avisar nada.

COMO INSTALAR E USAR (Windows)
-------------------------------
1. Dê um duplo clique no arquivo:
       Compactador de PDF.exe

   Pronto — é só isso. Esse .exe já vem pronto nesta pasta, funciona
   sozinho e NÃO precisa instalar Python nem nenhum outro programa. Pode
   mover só esse arquivo para onde quiser (ex: Área de Trabalho) e, se
   quiser, apagar o resto da pasta — ele funciona sozinho de qualquer
   lugar.

   (Se o Windows mostrar um aviso do "SmartScreen" dizendo que o
   aplicativo não é reconhecido, é porque o .exe é novo e ainda não foi
   baixado por muita gente — clique em "Mais informações" e depois em
   "Executar assim mesmo". Não é vírus.)

2. O programa abrirá uma janela com três abas:
   - "Compactar PDF": selecione um ou vários PDFs, escolha o tamanho
     máximo desejado e clique em "Compactar PDF(s)". Os arquivos
     compactados são salvos com o sufixo "_compactado" na mesma pasta do
     original (ou na pasta que você escolher).
   - "Fotos → PDF": selecione uma ou várias fotos e clique em
     "Converter em PDF". Cada foto vira um arquivo PDF separado, com o
     mesmo nome da foto — sem opções de tamanho/compactação, é direto.
   - "Juntar PDF": selecione os PDFs que quer combinar, use os botões
     "Mover para cima" / "Mover para baixo" para colocá-los na ordem
     desejada (a lista mostra a numeração 1, 2, 3... dessa ordem), escolha
     onde salvar o arquivo final e clique em "Juntar PDFs". Os arquivos
     são combinados nessa ordem — quando um termina de página, o próximo
     começa em seguida — e o resultado é sempre 1 único arquivo PDF (esta
     aba nunca divide o resultado em partes, mesmo que fique grande; se
     precisar de um arquivo menor depois de juntar, use a aba "Compactar
     PDF" no resultado).

   Na aba "Compactar PDF", o tamanho máximo tem 3 opções:
     • 12 MB
     • 5 MB
     • "Outro tamanho" — digite o valor que quiser em MB

   Se o arquivo não couber no tamanho escolhido mesmo no nível máximo de
   compactação (sem deixar as imagens ilegíveis), o programa divide o PDF
   automaticamente em quantas partes forem necessárias, cada uma dentro
   do limite, salvando como:
       nome_compactado_parte1_de_3.pdf
       nome_compactado_parte2_de_3.pdf
       nome_compactado_parte3_de_3.pdf
   (Isso não se aplica a fotos convertidas em PDF, já que cada foto vira
   sempre 1 única página — não há o que dividir.)

   Se você selecionar vários arquivos, eles são compactados/convertidos AO
   MESMO TEMPO (em paralelo, aproveitando os núcleos do processador), não
   um de cada vez — por isso processar vários arquivos juntos é bem mais
   rápido do que rodar o programa várias vezes seguidas.

   Enquanto processa, uma barra de progresso e um contador de arquivos
   concluídos aparecem na tela — isso é normal e mostra que o programa
   está trabalhando, mesmo que pareça parado por alguns segundos em
   arquivos grandes. O botão "Cancelar" interrompe o processamento de
   todos os arquivos a qualquer momento.

SOBRE OS OUTROS ARQUIVOS DA PASTA (uso avançado, opcional)
------------------------------------------------------------
Para usar o programa você só precisa do "Compactador de PDF.exe" (veja
"COMO INSTALAR E USAR" acima) — os arquivos abaixo não são necessários no
dia a dia, só existem para quem for mexer no código ou publicar uma
versão nova:

- "app.py", "requirements.txt", "Compactador de PDF.bat",
  "Abrir Compactador de PDF.vbs": a versão do programa como script Python
  (o código-fonte). É a partir daqui que o .exe é gerado.
- "Criar EXE.bat": regenera o "Compactador de PDF.exe" a partir do
  código-fonte (usa uma ferramenta chamada PyInstaller). Só precisa disso
  se você alterar o "app.py" e quiser um .exe novo na sua própria máquina.
- "Publicar Nova Versao.bat": publica uma versão nova no GitHub — é o que
  faz o auto-update (item 4 acima) funcionar para quem já tem o programa
  instalado. Veja o repositório em
  https://github.com/ULTRINH4/pdf-compact

COMO FUNCIONA A COMPACTAÇÃO
----------------------------
O programa primeiro faz uma limpeza sem perda de qualidade (remove dados
redundantes do PDF). Se o arquivo ainda estiver acima do limite, ele reduz
progressivamente a qualidade e a resolução apenas das IMAGENS dentro do
PDF — o texto (quando existe como texto pesquisável) não é convertido em
imagem, então continua nítido e pesquisável. O programa usa o tamanho atual
do arquivo para estimar de cara qual o nível de compactação necessário
(em vez de testar dezenas de combinações uma por uma), decodifica cada
imagem apenas uma vez e recompacta várias imagens ao mesmo tempo
aproveitando os núcleos do processador — por isso costuma terminar em
poucos segundos, mesmo em PDFs grandes. Esse mesmo aproveitamento dos
núcleos é compartilhado entre todos os arquivos quando você processa
vários de uma vez, então selecionar vários arquivos não sobrecarrega o
computador além do que já acontecia com um arquivo só.

IMPORTANTE: a compactação tem um limite máximo de agressividade, escolhido
propositalmente para nunca deixar texto ou imagens digitalizadas
ilegíveis. Se mesmo nesse limite máximo o arquivo continuar acima do
tamanho escolhido, o programa NÃO compacta mais que isso (para não
arriscar a qualidade) — em vez disso, divide o PDF em partes numeradas,
cada uma dentro do limite (veja o passo 2 acima). Se uma única página
sozinha já for maior que o limite escolhido (raro, mas pode acontecer com
uma imagem de resolução extrema), essa parte específica fica marcada com
um aviso ⚠, já que não é possível dividir uma página ao meio.

DÚVIDAS FREQUENTES
--------------------
- "O programa não abre / nenhuma janela aparece": se você extraiu a pasta
  inteira de dentro de um .zip, confira se extraiu tudo antes de abrir o
  .exe (clique direito no .zip → "Extrair Tudo..."), em vez de rodar de
  dentro do .zip direto. Se mesmo assim não abrir nada, veja se sobrou um
  arquivo "erro.log" na pasta — ele contém o motivo exato do erro.
- "O Windows mostrou um aviso do SmartScreen ('O Windows protegeu o
  computador')": é o aviso padrão para programas novos que ainda não
  foram baixados por muita gente, não é vírus. Clique em
  "Mais informações" e depois em "Executar assim mesmo".
- "O programa parece travado": olhe a barra de progresso e o texto de
  status acima da área de log — se estiverem se movendo/atualizando, o
  programa está processando normalmente. PDFs muito grandes (muitas
  páginas ou imagens de altíssima resolução) podem levar mais tempo. Use
  o botão "Cancelar" se quiser interromper.
- "O PDF final não ficou abaixo do limite": normalmente isso não deve
  acontecer mais, porque o programa divide automaticamente em partes
  quando necessário. Se ainda assim uma parte específica aparecer com o
  ícone ⚠, é porque uma única página sozinha (ex: uma foto de resolução
  extrema) já é maior que o limite escolhido, e não dá pra dividir uma
  página ao meio. Nesse caso, tente escolher um tamanho máximo maior.
- "Minhas fotos são .HEIC (iPhone) e não funcionam": o programa já tenta
  suportar esse formato automaticamente. Se der erro, tente converter a
  foto para .JPG primeiro (o próprio iPhone permite isso ao compartilhar).
