# Compactador de PDF e Fotos em PDF

Programa para Windows que compacta PDFs para um tamanho máximo escolhido
(útil para sistemas judiciais como PJe, e-SAJ, Projudi), transforma fotos
em PDF e junta vários PDFs em um só. Se atualiza sozinho.

[![Baixar Compactador de PDF.exe](https://img.shields.io/badge/⬇️_Baixar-Compactador%20de%20PDF.exe-2ea44f?style=for-the-badge)](https://github.com/ULTRINH4/pdf-compact/releases/latest/download/Compactador.de.PDF.exe)

Esse link sempre baixa a versão mais nova publicada — não precisa
procurar nos [Releases](https://github.com/ULTRINH4/pdf-compact/releases).
Depois de baixar, é só dar duplo clique. Não precisa instalar Python nem
mais nada. Veja o [LEIA-ME.txt](LEIA-ME.txt) para instruções detalhadas.

> ⚠️ **O Windows Defender/SmartScreen pode acusar o `.exe` como vírus ou
> bloquear o download — isso é um falso positivo.** Programas Python
> empacotados como `.exe` (feitos com PyInstaller, como este) costumam cair
> nesse alerta porque o arquivo ainda não tem "reputação" (poucas pessoas
> baixaram) e o programa não é assinado digitalmente — não é porque tem
> algo malicioso dentro. O código-fonte deste repositório é público, pode
> conferir. Se aparecer o aviso:
> - No navegador, clique em "Manter" / "Manter mesmo assim".
> - No SmartScreen do Windows ("O Windows protegeu o computador"), clique
>   em "Mais informações" → "Executar assim mesmo".
> - Se o Defender colocar o arquivo em quarentena, vá em
>   *Segurança do Windows → Proteção contra vírus e ameaças → Histórico de
>   proteção*, encontre o item e escolha "Permitir".
