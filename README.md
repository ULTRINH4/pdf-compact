# Compactador de PDF e Fotos em PDF

Programa para Windows que compacta PDFs para um tamanho máximo escolhido
(útil para sistemas judiciais como PJe, e-SAJ, Projudi), transforma fotos
em PDF e junta vários PDFs em um só. Se atualiza sozinho.

[![Baixar Compactador de PDF.exe](https://img.shields.io/badge/⬇️_Baixar-Compactador%20de%20PDF.exe-2ea44f?style=for-the-badge)](https://github.com/ULTRINH4/pdf-compact/releases/latest/download/Compactador.de.PDF.exe)

Esse link sempre baixa a versão mais nova publicada — não precisa
procurar nos [Releases](https://github.com/ULTRINH4/pdf-compact/releases).
Depois de baixar, é só dar duplo clique. Não precisa instalar Python nem
mais nada. Veja o [LEIA-ME.txt](LEIA-ME.txt) para instruções detalhadas.
